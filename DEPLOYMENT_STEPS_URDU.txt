DashBoard2 Vercel Deployment Steps

1) GitHub repo me ye clean project upload karein.
   Important: node_modules aur .env upload na karein.

2) Backend project deploy karein:
   - Vercel > Add New Project
   - Same GitHub repo select karein
   - Root Directory: backend
   - Environment Variables:
     MONGO_URI = your MongoDB Atlas URI
     CLIENT_URL = https://your-frontend.vercel.app
   - Deploy
   - Test URL: https://your-backend.vercel.app/health

3) Frontend project deploy karein:
   - Vercel > Add New Project
   - Same GitHub repo select karein
   - Root Directory: frontend
   - Framework Preset: Vite
   - Build Command: npm run build
   - Output Directory: dist
   - Environment Variables:
     VITE_API_URL = https://your-backend.vercel.app/api
   - Deploy

4) Backend me CLIENT_URL update karein:
   - Frontend deploy hone ke baad frontend ka final Vercel URL copy karein
   - Backend project > Settings > Environment Variables
   - CLIENT_URL me frontend URL paste karein
   - Backend ko redeploy karein

5) MongoDB Atlas:
   - Network Access me IP allow karein.
   - Development/testing ke liye 0.0.0.0/0 use kar sakte hain.
   - Production ke liye restricted access better hai.
